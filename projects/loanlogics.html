A hands-on web design and frontend project for LoanLogics, where I designed and built the CARBN page and marketing banners using HTML and CSS. My contribution covered both the visual design and the frontend implementation.

Client LoanLogics
Role UI/UX Designer & Frontend Developer
Project CARBN Page & Marketing Banners
Industry FinTech / Mortgage Technology
Technologies HTML & CSS
Delivery Previously live website

01 — Problem

LoanLogics needed a dedicated CARBN web page and supporting marketing banners to communicate its offering through the website.

The work involved creating the page and banner visuals and translating those designs into working frontend code.

02 — My Role

I handled both the design and frontend implementation of the CARBN page and marketing banners. Rather than handing off static designs alone, I also built the page using HTML and CSS.

UI Design

  • Designed the CARBN page layout.
  • Worked on content presentation and visual hierarchy.
  • Designed supporting marketing banners.
  • Maintained consistency with the website experience.

Frontend Development

  • Built the CARBN page using HTML.
  • Styled the page using CSS.
  • Implemented the designed layouts in the website.
  • Worked on translating the visual design into a working page.

03 — Constraints

  • The page needed to align with the existing LoanLogics website and brand experience.
  • The design needed to communicate the CARBN offering clearly through its page layout.
  • The marketing banners needed to fit the website's visual language and content.
  • The final design needed to be implemented using HTML and CSS.

04 — Key Design Decisions & Trade-offs

Page Structure & Content Hierarchy

Designed the CARBN page to present its content in a structured way, making the information easier to navigate and understand.

Visual Consistency

Kept the page and banner designs aligned with the existing LoanLogics website experience.

Design-to-Code Execution

Built the page using HTML and CSS, translating the visual design into a functioning website experience.

Page & Banner Coordination

Designed the CARBN page and its supporting marketing banners as part of the wider website experience.
